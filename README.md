# 教会动态聚会系统 ✝️

> 一套开源、轻量、无需服务器的 **教会主日崇拜流程展示系统**，支持完整24页流程配置，适用于投影、大屏、线上同步等场景。

![示例界面](https://via.placeholder.com/800x400/e74c3c/ffffff?text=教会聚会系统+界面截图) <!-- 你上线后可替换为真实截图 -->

## 📌 特色功能

- ✅ **完整24页标准流程**：欢迎、宣召、敬拜、经文、讲道、奉献、圣餐、祝福等
- ✅ **可视化配置界面**：无需改代码，通过网页表单编辑内容
- ✅ **双模式数据管理**：
  - 默认从 `content.json` 加载（适合部署）
  - 运行时保存到浏览器 `localStorage`（适合临时调整）
- ✅ **一键复位**：Ctrl+R 或点击按钮，恢复24页默认流程
- ✅ **响应式设计**：适配投影仪、平板、手机
- ✅ **完全离线运行**：无网络也能使用
- ✅ **语音控制预留接口**（未来扩展）
- ✅ **开源免费**：MIT 协议，可自由修改、分发、用于任何教会
